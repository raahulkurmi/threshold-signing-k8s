# Run-to-run dispersion (7C main comparison, 7C stress test, v2 stress-storm)

Generated by `benchmark/dispersion` (`cd benchmark && go run ./dispersion`) from the committed raw data only; nothing is typed by hand. Paper support: no system code was changed (freeze rule), and no results directory or `summary.md` is modified.

Definitions are those of `benchmark/summarize`: **median** = nearest-rank p50 latency (ms) over the successful requests of one run; **goodput** = successful tokens / (last end − first start over all requests of the run), tokens/s; **wasted on failed %** = computed shares (signer audit `allow` entries) for requests the coordinator failed, as % of all computed shares in that run. **min – max** is across runs; **spread %** = (max − min) / median of runs. The **median of runs** columns are the values `summary.md` reports.

**Self-check before writing:** every per-run median and goodput below was recomputed from the CSVs and matched the `All configurations, every run` table of the session's `summary.md` (72 rows in 7C main, 18 in 7C stress, 63 in v2 stress-storm); the median of runs of goodput/peak and wasted % matched the 7C stress table (6 rows), the v2 session's N76 table (18 rows) and its N77 storm table (3 rows). Any mismatch aborts the script.
